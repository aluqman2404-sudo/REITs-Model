# Signal Component Definitions

## Valuation

- Basis: Stage 4 fair-value gap / Stage 6 mispricing layer
- Evidence status: `empirically supported`
- Interpretation: the strongest current historical signal, especially over medium horizons

## Cycle / Momentum

- Basis: scenario-linked cycle view plus Stage 6 regime layer
- Evidence status: `partially supported`
- Interpretation: useful context, but weaker and less clean than valuation as a stand-alone ranking signal

## Downside Resilience

- Basis: simulation downside probability / tail context
- Evidence status: `descriptive`
- Interpretation: scenario-plausibility context, not a validated forecast edge

## Affordability

- Basis: user income, deposit, mortgage rate, mortgage term, LTI, LTV
- Evidence status: `descriptive`
- Interpretation: relevant for the user decision, but not backtested as a predictive market-timing signal

## Yield Support

- Basis: current gross yield versus user hurdle
- Evidence status: `descriptive`
- Interpretation: useful for REIT-style context, but not validated as a full alpha signal

## Secondary synthesis

- Basis: weighted summary of the signals above
- Evidence status: `secondary only`
- Interpretation: compact summary, not the primary research object
