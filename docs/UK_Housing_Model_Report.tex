\begin{abstract}
\noindent
This report documents the full development of the UK Housing Market Model,
a Python-based quantitative tool that ingests real UK housing market data,
calibrates a stochastic differential equation (SDE) using Ordinary Least
Squares (OLS) regression, runs Monte Carlo simulations of future price
trajectories, and outputs a scored \textit{Buy / Hold / Don't Buy}
recommendation for two distinct user groups: retail home buyers and
Real Estate Investment Trusts (REITs).

The project spans approximately 300 hours of development across seven stages:
environment setup, data acquisition, data cleaning, OLS calibration, SDE
simulation, scoring engine design, and interactive UI deployment. Each stage
is documented in this report with the decisions made, the methods applied,
the code implemented, and the results obtained.

\vspace{0.5em}
\noindent\textbf{Keywords:} UK housing market, stochastic differential equations,
Ornstein-Uhlenbeck process, Monte Carlo simulation, OLS calibration,
affordability scoring, REIT analysis, Streamlit.
\end{abstract}

\chapter{Introduction}

\section{Motivation}

The UK housing market is one of the most consequential financial markets for
both individual households and institutional investors. Despite its size and
importance, accessible quantitative tools for evaluating entry timing remain
scarce for retail buyers, and REIT-grade analytics are typically locked behind
expensive proprietary platforms.

This project builds an open, transparent model that:
\begin{itemize}
  \item Uses publicly available UK data (HM Land Registry, ONS, Bank of England)
  \item Applies rigorous econometric calibration via OLS regression
  \item Simulates future price uncertainty using a mean-reverting SDE
  \item Translates model output into a simple, interpretable score
  \item Delivers results through an interactive web application
\end{itemize}

\section{Objectives}

Ordinary Least Squares regression connects observed historical data to the

\section{Regression Specification}

\mytodo{Fill in your chosen specification once decided.}

The baseline regression equation for monthly real house price growth is:

\begin{equation}
  \Delta \ln P_{r,t} = \alpha + \beta_1 \Delta \ln Y_{r,t} + \beta_2 \Delta r_t
    + \beta_3 \ln \text{PIR}_{r,t-1} + \beta_4 \Delta \ln N_{r,t} + \varepsilon_{r,t}
  \label{eq:ols}
\end{equation}

where $P_{r,t}$ is real house price in region $r$ at time $t$, $Y_{r,t}$ is
real income, $r_t$ is the BoE base rate, $\text{PIR}_{r,t-1}$ is the lagged
price-to-income ratio (error correction term), and $N_{r,t}$ is regional
population.

\chapter{Stage 5: SDE Simulation}
%% ============================================================
\textit{Estimated: 50--60 hours \quad Actual: \mytodo{fill in}}

\section{Objectives}

The Stochastic Differential Equation captures the dynamic and uncertain
nature of UK house prices over time. The simulation generates a distribution
of future price paths which feeds directly into the scoring engine.

\section{Choice of SDE: Ornstein-Uhlenbeck Process}

\mytodo{Confirm this choice or update if a different process was selected.}

The Ornstein-Uhlenbeck (OU) process was selected for its mean-reverting
property, which is economically motivated: in the long run, house prices
cannot diverge indefinitely from fundamental values (income, rent yields).
The continuous-time SDE is:

\begin{equation}
  dP_t = \theta(\mu - P_t)\,dt + \sigma\,dW_t
  \label{eq:ou}
\end{equation}

where:
\begin{itemize}
  \item $\theta > 0$ is the mean reversion speed (rate at which prices return to $\mu$)
  \item $\mu$ is the long-run equilibrium price level
  \item $\sigma > 0$ is the diffusion coefficient (price volatility)
  \item $W_t$ is a standard Brownian motion
\end{itemize}

\subsection{Comparison with Geometric Brownian Motion}

Geometric Brownian Motion (GBM), the standard Black-Scholes model for equities,
was considered but rejected because:

\begin{enumerate}
  \item GBM has no mean reversion --- prices can drift to zero or infinity
  \item Housing markets exhibit documented cyclicality and affordability constraints
  \item The OU process has a closed-form stationary distribution:
        $P_\infty \sim \mathcal{N}\!\left(\mu,\,\frac{\sigma^2}{2\theta}\right)$
\end{enumerate}

\section{Numerical Discretisation: Euler-Maruyama}

The continuous SDE is discretised using the Euler-Maruyama scheme with a
monthly time step ($\Delta t = \frac{1}{12}$):

\begin{equation}
  P_{t+\Delta t} = P_t + \theta(\mu - P_t)\Delta t + \sigma\sqrt{\Delta t}\,Z_t, \quad
  Z_t \sim \mathcal{N}(0,1)
  \label{eq:euler}
\end{equation}

\section{Monte Carlo Simulation}

$N = 10{,}000$ price paths are generated per region per scenario. The
simulation outputs three summary series used by the scoring engine:

\begin{align}
  \hat{P}^{(10)}_t &= \text{10th percentile of simulated prices at time } t \\
  \hat{P}^{(50)}_t &= \text{50th percentile (median)} \\
  \hat{P}^{(90)}_t &= \text{90th percentile}
\end{align}

These correspond to the Bear, Base, and Bull scenarios respectively.

\section{Objectives}

The scoring engine transforms the Monte Carlo simulation output into a

\section{Score Architecture}

Each score is a weighted average of component sub-scores, each normalised
to a 0--100 scale using the historical distribution of that variable.

\subsection{Consumer Score}

\begin{equation}
  S^{\text{consumer}} = w_1 A + w_2 M + w_3 C + w_4 R
  \label{eq:consumer-score}
\end{equation}

where:
\begin{itemize}
  \item $A$ = affordability index (price-to-income, user's income vs region)
  \item $M$ = price momentum signal from Monte Carlo (upside/downside balance)
  \item $C$ = cycle position (where current prices sit in the long-run distribution)
  \item $R$ = rate environment score (mortgage rate affordability)
\end{itemize}

Default weights: $w_1 = 0.40,\ w_2 = 0.25,\ w_3 = 0.20,\ w_4 = 0.15$

\mytodo{Confirm or update these weights after calibration.}

\subsection{REIT Score}

\begin{equation}
  S^{\text{REIT}} = w_1 Y + w_2 C + w_3 M + w_4 \text{RAR}
  \label{eq:reit-score}
\end{equation}

where $Y$ = gross yield score, $C$ = cycle position, $M$ = price momentum,
$\text{RAR}$ = risk-adjusted return score.

Default weights: $w_1 = 0.35,\ w_2 = 0.30,\ w_3 = 0.20,\ w_4 = 0.15$
